# ignaciosimone.github.io

Portfolio personal de **Ignacio Simone Sánchez** — Analista de Business Intelligence e Ingeniero en Software.

👉 **https://ignaciosimone.github.io**

## Cómo está hecho

- HTML, CSS y JavaScript sin herramientas de compilación: se publica tal cual con GitHub Pages.
- Animaciones de scroll con [GSAP](https://gsap.com) + ScrollTrigger y scroll suave con [Lenis](https://lenis.darkroom.engineering).
- Gráficos en SVG y maqueta de la app en HTML: nítidos en cualquier pantalla, sin imágenes pesadas.
- Español e inglés (`i18n.js`), y respeta la preferencia del sistema de reducir animaciones.

## Editar

- Textos en español: directamente en `index.html`. Textos en inglés: `i18n.js` (misma clave `data-i18n`).
- Estilos: `styles.css` (colores en las variables de `:root`).
- Animaciones: `main.js`.

Para verlo localmente alcanza con abrir `index.html` en el navegador.
