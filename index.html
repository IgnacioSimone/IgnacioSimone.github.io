003Proyecto destacado

PBI Layer

Aplicación de escritorio open source que documenta cualquier modelo de Power BI en segundos. La diseñé y desarrollé de punta a punta.

  1. Todo el modelo, de un vistazo Se conecta al tablero abierto en Power BI Desktop y reúne medidas DAX, tablas, columnas y Power Query.
  2. Mapa de relaciones Las tablas como un mapa: cardinalidad, dirección del filtro y relaciones inactivas.
  3. Uso y limpieza Detecta medidas, columnas y consultas que nada usa, cruzando visuales, fórmulas y relaciones.
  4. Documentación lista para compartir Exporta a Word, Excel, HTML y un Markdown para analizar el modelo con IA. Solo metadata, nunca datos.
